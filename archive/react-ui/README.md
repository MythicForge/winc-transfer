# Archived: React UI (≤ 0.8.0)

The original React/TypeScript front end, retired in 0.9.0 when the UI was
rewritten in Rust (Leptos) — see `../../ui/`. Kept for reference only; Tauri
no longer builds or loads it.

To preview it in mock mode anyway:

```bash
cd archive/react-ui
npm install
npm run dev      # http://localhost:5173
```
